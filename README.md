Third-year Computer Science Engineering student (CGPA 7.65, Batch 2024–2028, Chennai Institute of Technology).
My focus is privacy-preserving ML — federated learning, differential privacy, and gradient security — with blockchain used to enforce trust in AI pipelines where centralised verification is not feasible.

## Ongoing Research

**BOPFL — Blockchain-Orchestrated Privacy-Preserving Federated Learning**

Studying how to verify federated model updates without exposing gradients. Working through privacy-trust-efficiency tradeoffs in current approaches to fine-tuning LLMs across distributed clients.

`Federated Learning` · `Differential Privacy` · `ZK Proofs` · `LLM Fine-tuning` · `On-chain Verification`
